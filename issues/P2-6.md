# P2-6 — Cache-failure handling was asymmetric. Writes wrapped `cacheRemove()` …

## Finding / 问题

- EN: Cache-failure handling was asymmetric. Writes wrapped `cacheRemove()` in `try/catch (\Throwable)` and logged a warning; the read paths called `cache()->get()` and `set()` unguarded, so a cache outage failed reads while writes still succeeded. Fixed in the working tree by wrapping, logging and degrading the reads to the database, with the initialisation guard left outside the `try`; no reviewer has verified that fix yet, so this arrives `open`.
