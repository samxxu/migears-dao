# P2-5 — `domainId()` read the primary key with `get_object_vars()`, evaluated …

## Finding / 问题

- EN: `domainId()` read the primary key with `get_object_vars()`, evaluated in the DAO's scope, so it saw only public properties. With a non-public key it returned `null` and `getByIds()` fell back to the requested id, returning the same row twice for `getByIds(['01', 1])`. Fixed in the working tree by a per-`(domainClass, idColumn)` cached `\ReflectionProperty`, with a `private readonly` key fixture; no reviewer has verified that fix yet, so this arrives `open`.
- 中文: `domainId()` 用 `get_object_vars()` 读主键，而该函数在 DAO 作用域内取值，因此只看得见 public 属性。主键非 public 时返回 `null`，`getByIds()` 回退到请求的 id，于是 `getByIds(['01', 1])` 把同一行返回两次。工作树中已修：按 `(domainClass, idColumn)` 缓存的 `\ReflectionProperty`，配 `private readonly` 主键夹具。该修复尚无评审方核实，因此本条以 `open` 到来。
- Where / 位置: `src/CachedDao.php:116-141`
- Verification / 验证: reproduced / 已实证
